## Run locally

No build or installation is required. Serve `docs/` with any static HTTP server, for example `python3 -m http.server 8080 --directory docs`.

GitHub Pages publishes the `docs/` folder on `main`. Scripts and documentation in this repository use the MIT license. Product screenshots retain their owners' rights; trailer imagery is credited to Rockstar Games. No sample media is redistributed in this repository.
